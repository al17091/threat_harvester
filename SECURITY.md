# Security Policy & Responsible Use Guidelines

## 1. Responsible Use & Legal Disclaimer

**Threat Harvester** is developed strictly for **defensive Cyber Threat Intelligence (CTI)**, security research, risk mitigation, and educational purposes.

- **Passive Intelligence Gathering Only**: This tool collects publicly available or leak-notification metadata from public channels, search feeds, and Tor-accessible public leak portals. It does not perform active exploitation, network intrusion, or bypass access control mechanisms.
- **Compliance with Laws & Regulations**: Users are responsible for ensuring that their deployment and use of this tool comply with all applicable local, national, and international laws (including Japan's Penal Code Article 168-2/3 regarding Unauthorized Computer Access, export regulations, and privacy statutes).
- **No Liability**: The authors and contributors assume no liability for misuse, damages, or violations caused by the operation of this software.

---

## 2. Reporting a Security Vulnerability

We take the security of this project seriously. If you discover a security vulnerability in this application or its container configurations, please report it privately:

1. **Do NOT report security vulnerabilities via public GitHub issues.**
2. Submit a private report via **[GitHub Security Advisories (Private Vulnerability Reporting)](https://github.com/al17091/threat_harvester/security/advisories/new)** with:
   - A clear description of the vulnerability.
   - Steps or proof-of-concept (PoC) to reproduce the issue.
   - Potential impact and suggested mitigations.
3. We will acknowledge receipt of your report within 48 hours and work with you to remediate and publish a patch.
